## 📖 Sobre o Projeto  
**ExpireSoon** é um aplicativo mobile desenvolvido em **React Native**, que conecta empresas e consumidores para vender produtos próximos do vencimento, evitando desperdícios e permitindo economia.  

🚀 Com **ExpireSoon**, empresas anunciam seus produtos, e consumidores podem buscar ofertas com filtros personalizados.  

---

## ✨ **Funcionalidades**
✔️ **Cadastro de Empresas e Produtos**  
✔️ **Barra de pesquisa com filtros inteligentes**  
✔️ **Sistema de Prioridade para Anunciantes Premium**  
✔️ **Processamento de pagamento integrado**  
✔️ **Recomendações de produtos similares**  
✔️ **Modo escuro para melhor experiência do usuário**  

---

## 🛠 **Tecnologias Utilizadas**
- ⚛ **React Native** (Desenvolvimento Mobile)  
- 💙 **React Navigation** (Navegação no app)  
- 🖼 **React Native Paper** (Componentes visuais modernos)
